Здравствуйте.

Тема моей работы — «Мессенджер AJAX».

Целью проекта была разработка веб-приложения для обмена сообщениями между пользователями с использованием современных технологий разработки и эксплуатации программного обеспечения.

В рамках проекта была реализована микросервисная архитектура, состоящая из нескольких компонентов: веб-клиента, сервиса пользователей, сервиса сообщений и базы данных PostgreSQL.

Для разработки серверной части использовался язык Python и фреймворк Flask. Данные пользователей и сообщений хранятся в PostgreSQL.

Для обеспечения переносимости и удобства развертывания все компоненты были контейнеризированы с использованием Docker.

Развертывание приложения выполнено в Kubernetes-кластере в облачной инфраструктуре Yandex Cloud. Для управления конфигурациями использовались Helm-чарты.

Для автоматизации процессов сборки и развертывания был настроен CI/CD-конвейер на базе Jenkins. После внесения изменений в репозиторий автоматически выполняется сборка контейнеров и обновление приложения в Kubernetes.

Для мониторинга системы был внедрен стек Prometheus и Grafana. Собираются метрики самого кластера Kubernetes, виртуальных машин, базы данных PostgreSQL и разработанных Flask-сервисов.

Для централизованного логирования используется Loki и Promtail, что позволяет оперативно анализировать работу приложения и выявлять ошибки.

В результате был создан работоспособный веб-мессенджер с современной облачной инфраструктурой, автоматизированным развертыванием, мониторингом и системой логирования.

Проект может быть расширен за счет внедрения WebSocket для обмена сообщениями в режиме реального времени, JWT-аутентификации, масштабирования сервисов и повышения отказоустойчивости базы данных.

Спасибо за внимание.
